# 🎵 音乐搬家 (Music Mover)

👉 **直接食用**：[https://sunld666.github.io/music-mover/](https://sunld666.github.io/music-mover/)

这是一款轻量、安全、纯本地运行的智能歌单整理工具。

如果你有一份列满歌曲名字的 TXT 文本（例如从音乐软件导出的歌单），同时你的电脑里有一个庞大但杂乱的本地音乐库。这个工具可以帮你**自动在本地库中找出歌单里的歌**，并**批量复制**到一个全新的文件夹中，轻松完成音乐的“搬家”！

## ✨ 核心功能

- 🔒 **纯前端运行**：利用现代浏览器 API 直接读取本地文件，无需上传服务器，保护隐私。
- 🧠 **多级智能匹配**：自动识别 `歌名 - 歌手` 格式，支持精准匹配、纯歌名匹配和模糊搜索，最大程度防止漏歌。
- 📂 **深度扫描**：自动遍历你选择的音乐文件夹及其所有子文件夹。
- ⚙️ **灵活配置**：支持自定义生成文件夹名称，遇到同名文件可选择“跳过”或“覆盖”。
- 📊 **完善的报告**：提供详细的运行日志，并支持一键导出“未找到的缺漏歌曲”清单。

## 🚀 使用方法

整个过程只需简单的 4 步：

1. **准备歌单**：准备一个 `.txt` 格式的文本文件，里面按行写满你想找的歌曲（推荐格式：`歌名 - 歌手`）。
   > 💡 **特别致谢与推荐**：强烈推荐搭配浏览器插件 **[小熊歌单搬家]** 使用！你可以用它一键将各大在线音乐平台的歌单导出为纯文本 (TXT) 格式，然后再使用本工具在本地硬盘中匹配并搬运音乐。在此对“小熊歌单搬家”的开发者表示衷心的感谢！❤️

2. **导入文件**：在网页“步骤 1”中导入你的 TXT 歌单，网页会自动解析并在下方显示歌曲预览。
3. **授权目录**：在“步骤 2”中点击按钮，授权你的本地音乐主文件夹。
4. **一键搬家**：在“步骤 3”设置好导出位置和文件夹名字，点击“开始搬家”。完成后，还可以下载整理报告！
